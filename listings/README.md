# listings

One authored TOML document per listing, at `listings/<id>.toml`, for the watched content types `mod` and `mod-loader`.

The file name is the content id, which for a mod is the folder name it installs as, because the game takes the id from the folder name and overwrites whatever the archive declares (`Mod.MakeUsing`).

Mod packs live in `packs/` instead.
